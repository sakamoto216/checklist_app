# FEAT-2025-001: Android用APKビルド

## 概要
EAS Buildを使用してAndroid APKファイルを生成できる機能を実装

## 背景・目的
- **なぜ必要か**: アプリの配布・テストのためにAPKファイルが必要
- **提供価値**: 開発版・プレビュー版・本番版のAPKビルドが可能
- **優先度**: High

## 受け入れ条件
- [x] eas.jsonファイルの作成と設定
- [x] package.jsonにビルドスクリプトを追加
- [ ] APKビルドの動作確認（要Expoアカウント）

## 技術的な詳細
- **使用技術**: EAS Build, Expo CLI
- **影響ファイル**: eas.json, package.json
- **依存関係**: Expoアカウントでのログインが必要
- **制約・注意点**: EAS Buildはクラウドビルドサービス

## Claude Code指示
このチケットを実装する際は以下の順序で作業してください：
1. eas.jsonファイルを作成してビルド設定を定義
2. package.jsonにAndroidビルド用のスクリプトを追加
3. ビルド手順をドキュメント化

重要: 実際のAPKビルドにはExpoアカウントログインが必要
